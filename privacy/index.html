1. 이 방침이 다루는 것

수학은유강이 운영하는 내부 도구(수업 영상 색인 프로그램 mathis-yt)와 학생 안내 웹페이지에 적용됩니다.

2. 수집·이용하는 정보

mathis-yt 는 운영자 본인의 YouTube 채널에 대해 영상 목록(제목·길이·공개 상태·업로드일)과 자막을 읽어 수업 자료 색인을 만듭니다. 이 도구는 운영자 계정만 사용하며, 제3자의 Google 계정 정보나 시청 기록을 수집하지 않습니다. 학생 안내 웹페이지는 방문 통계 외의 개인정보를 수집하지 않습니다.

3. 보관과 제3자 제공

수집한 영상 목록·자막은 수업 자료 제작 목적으로만 운영자 저장소에 보관하며, 제3자에게 제공하거나 판매하지 않습니다. Google 사용자 데이터의 이용은 Google API 서비스 사용자 데이터 정책의 제한 사용 요건을 따릅니다.
