x² + y² + Ax + By + C = 0 꼴은 완전제곱으로 정리하면 중심과 반지름이 보인다.

Q1y=x 대칭이동지난 수업
직선 y = x 에 대한 대칭이동은 식을 어떻게 바꿀까?
풀이

y = x 대칭은 점 (a, b) 가 (b, a) 로 간다. 좌표가 통째로 자리를 바꾸는 것이다.

그래서 식에서도 x 와 y 를 맞바꾸면 된다.

y = 2x + 3 은 x = 2y + 3, 즉 y = (x − 3) / 2 가 된다.

Q2y축 대칭이동지난 수업
포물선 y = x² − 4x + 5 를 y축에 대하여 대칭이동하면?
풀이

y축 대칭은 x 대신 −x 만 넣는다.

y = (−x)² − 4(−x) + 5 = x² + 4x + 5

x 의 짝수 차수 항은 그대로, 홀수 차수 항만 부호가 바뀐다.

PART 2
계속 걸리는 것
반에서 많이 틀린 문제. 계산은 해뒀으니 판단만 하면 돼
Q3평행이동의 원리 반에서 5명지난 오답
원 x² + y² = 9 를 x축 방향으로 2, y축 방향으로 −1 만큼 평행이동하려고 해.
① 식을 어떻게 바꿔야 할까?
② 부호가 왜 반대일까?
③ 그래서 옮긴 원의 중심은?
풀이

평행이동은 "점을 옮기는" 게 아니라 "그 자리에 원래 어떤 점이 있었나"를 되묻는 것이다.

옮긴 뒤 (x, y) 에 있는 점은 옮기기 전 (x−2, y+1) 에 있던 점이다. 그래서 식에 x−2, y+1 을 넣는다.

(x−2)² + (y+1)² = 9 → 중심 (2, −1), 반지름 3.

2. x² + y² + Ax + By + C = 0 을 완전제곱으로 정리하면

모범 답안

1번 — 원은 한 점에서 같은 거리에 있는 점의 모임이다. 원 위의 임의의 점을 P(x, y) 라 하면 CP = r 이므로, 두 점 사이의 거리 공식에 의해 √{(x−a)² + (y−b)²} = r 이고, 양변을 제곱하면 (x − a)² + (y − b)² = r² 이다.

2번 — (가) A/2, (나) B/2, (다) (A² + B² − 4C)/4. 우변이 0 이면 좌변의 두 제곱항이 모두 0 이어야 하므로, 이 식을 만족하는 점은 (−A/2, −B/2) 한 점뿐이다. 즉 원이 아니라 한 점을 나타낸다.
